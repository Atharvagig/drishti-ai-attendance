3. SECURITY & ROLE-BASED ACCESS CONTROL (RBAC)
-------------------------------------------------------------------------------
- Authentication: bcrypt salted password hashing with adaptive work factors.
- Brute-Force Protection: Automatic account lockout after 5 failed login attempts.
- CSRF Protection: Synchronizer token pattern with X-CSRFToken header validation.
- Session Cookies: HttpOnly=True, SameSite=Lax, Secure=True under HTTPS.
- Roles: Super Admin, Department Head, Faculty, Student.
- Production Admin Enforcement: Enforces custom ADMIN_PASSWORD in production.
